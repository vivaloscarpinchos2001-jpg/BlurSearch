# BlurSearch 🔍✨

**BlurSearch**  An iOS tweak that brings the new Settings search bar from iOS 16 to older iOS versions; it currently supports iOS 15 and iOS 16.

It uses the native iOS 16 SpringBoard dock blur effect!
